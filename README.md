# EShop React UI

React, TypeScript ve Material UI kullanılarak geliştirilen e-ticaret ön yüz (frontend) uygulaması.

## Mevcut Durum

- **Project Setup:** Gerekli bağımlılıklar (`@mui/material`, `react-icons` vb.) eklenerek proje altyapısı oluşturuldu.
- **Register Page:** Material UI bileşenleri ve ikonlar kullanılarak kayıt formu tasarımı ve sayfa düzeni yapılmaya başlandı.

## Tech Stack

- **Frontend:** React, TypeScript
- **UI & Icons:** Material UI (MUI), React Icons
