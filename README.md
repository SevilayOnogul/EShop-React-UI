# EShop React UI

React, TypeScript ve Material UI kullanılarak geliştirilen e-ticaret ön yüz (frontend) uygulaması.

## Mevcut Durum

- **Project Setup:** Gerekli bağımlılıklar (`@mui/material`, `react-icons`, `axios`, `react-toastify` vb.) eklenerek proje altyapısı oluşturuldu.
- **Register Page:** Material UI bileşenleri, Formik & Yup doğrulama kuralları ve Axios entegrasyonu ile kayıt formu tasarımı ve servis bağlantıları tamamlandı.
- **Login Page:** Material UI kullanılarak giriş formu arayüz tasarımı tamamlandı ve kullanıcı giriş servis altyapısı entegre edildi.

## Tech Stack

- **Frontend:** React, TypeScript
- **UI & Icons:** Material UI (MUI), React Icons
- **Form & Validation:** Formik, Yup
- **HTTP & Notifications:** Axios, React-Toastify
